คู่มือการใช้งาน

สำหรับผู้ใช้ทั่วไป

  1. กรอกข้อมูลให้ครบถ้วนแล้วกด "ส่งคำขอ"
  2. สแกน QR Code ที่ติดอยู่กับอุปกรณ์เพื่อกรอกข้อมูลอัตโนมัติ
  3. แนบรูปภาพ JPG/PNG/GIF ไม่เกิน 2MB
  4. ติดตามสถานะได้ที่แท็บ "ประวัติ"

สำหรับแอดมิน

  1. เข้าสู่ระบบด้วย Username และ Password
  2. จัดการฐานข้อมูลอุปกรณ์ ได้ที่เมนู "ฐานข้อมูลอุปกรณ์"
  3. สร้าง QR Code แปะที่อุปกรณ์เพื่อให้ผู้ใช้สแกนแจ้งซ่อม
  4. มอบหมายช่าง / เปลี่ยนสถานะงานได้ที่ "รายการแจ้งซ่อม"
